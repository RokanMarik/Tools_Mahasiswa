Peta Interaktif Bahasa Indonesia — Scope

Pertanyaan pertama: Website ini targetnya untuk siapa?

Kamu punya database lengkap dengan 14 tabel (bahasa, lokasi, kosakata, sejarah, manuskrip, dll). Pertanyaannya: siapa yang akan pakai website ini?

A

Publik Umum

Masyarakat umum yang penasaran dengan bahasa daerah. Fokus: peta interaktif yang menarik, search, info dasar bahasa. Simpel, visual, touch-friendly.

B

Peneliti & Akademisi

Linguistik, antropolog, mahasiswa. Fokus: data detail, filter advanced, export data, perbandingan bahasa, fitur linguistik lengkap.

C

Dua Target (Hybrid)

Mode "Explore" untuk publik + mode "Research" untuk akademisi. Satu website, dua pengalaman berbeda.

Data yang tersedia:

  • 📍 Koordinat geografis + polygon wilayah (PostGIS)
  • 📊 Jumlah penutur + vitalitas + tren historis
  • 🔤 Fitur linguistik (fonologi, morfologi, urutan kata)
  • 📖 Kosakata (Swadesh list + sampel)
  • 🎙️ Media: audio, video, teks sampel
  • 📜 Sejarah: peristiwa, pengaruh bahasa lain, manuskrip
  • 👥 Kontributor + sumber referensi
