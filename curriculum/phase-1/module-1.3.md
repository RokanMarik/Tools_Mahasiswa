## Hari 1-2: Teori + Contoh

### HOOK

Tidak perlu sempurna hari ini. Mari kita pelan-pelan.

Pernah pakai mesin cuci? Kamu masukkan baju kotor (input), mesin bekerja (proses), keluar baju bersih (output).

Itu konsep fungsi! Input → Proses → Output.

### CONCEPT

**Apa itu Fungsi?**

Fungsi adalah aturan yang mengubah input menjadi output.

Setiap input punya SATU output (tidak boleh dua).

Contoh fungsi: `f(x) = 2x + 1`
- `f` = nama fungsi
- `x` = input
- `2x + 1` = aturan (kalikan 2, lalu tambah 1)

Jika x = 3:
- f(3) = 2(3) + 1 = 6 + 1 = 7
- Input 3 → Output 7

**Notasi Fungsi:**

| Ditulis | Artinya |
|---------|---------|
| `f(x) = 2x + 1` | Fungsi f dengan input x |
| `f(3)` | Nilai f saat x = 3 |
| `y = f(x)` | y adalah output dari fungsi f |

**Tabel Nilai:**

Untuk fungsi `f(x) = 2x + 1`:

| x | f(x) = 2x + 1 | y |
|---|---------------|---|
| 0 | 2(0) + 1 = 1 | 1 |
| 1 | 2(1) + 1 = 3 | 3 |
| 2 | 2(2) + 1 = 5 | 5 |
| 3 | 2(3) + 1 = 7 | 7 |
| 4 | 2(4) + 1 = 9 | 9 |

**Grafik Fungsi Linear:**

Fungsi linear (`f(x) = mx + c`) menghasilkan garis lurus.

Koordinat Cartesius punya 2 sumbu:
- Sumbu **X** (horizontal) → input
- Sumbu **Y** (vertikal) → output

Plot titik-titik dari tabel:
- (0, 1), (1, 3), (2, 5), (3, 7), (4, 9)

Hubungkan titik-titik → dapat garis lurus!

**Slope (Kemiringan):**

Slope = berapa naik y untuk setiap kenaikan x.

Untuk `f(x) = 2x + 1`:
- Slope = 2
- Artinya: setiap x naik 1, y naik 2

💡 **Slope = koefisien x dalam fungsi linear.**

**Y-Intercept (Titik Potong Sumbu Y):**

Titik dimana garis memotong sumbu Y (saat x = 0).

Untuk `f(x) = 2x + 1`:
- Saat x = 0: f(0) = 1
- Y-intercept = 1

💡 **Y-intercept = angka yang ditambah/dikurang dalam fungsi.**

### WORKED EXAMPLE

**Soal 1:** Fungsi `f(x) = 3x − 2`. Hitung f(0), f(1), f(2).

**Penyelesaian:**

```
f(0) = 3(0) − 2 = 0 − 2 = −2
f(1) = 3(1) − 2 = 3 − 2 = 1
f(2) = 3(2) − 2 = 6 − 2 = 4
```

Titik-titik: (0, −2), (1, 1), (2, 4)

---

**Soal 2:** Dari tabel, tentukan slope dan y-intercept:

| x | y |
|---|---|
| 0 | 3 |
| 1 | 5 |
| 2 | 7 |

**Penyelesaian:**

```
Y-intercept: saat x = 0, y = 3 → y-intercept = 3

Slope: setiap x naik 1, y naik 2 → slope = 2

Fungsi: f(x) = 2x + 3
```

---

**Soal 3:** Gambar grafik `f(x) = x + 2`

**Penyelesaian:**

```
Buat tabel:
x | f(x) = x + 2
--|------------
0 | 2
1 | 3
2 | 4

Plot titik: (0,2), (1,3), (2,4)
Hubungkan → garis lurus dengan slope 1, y-intercept 2
```
