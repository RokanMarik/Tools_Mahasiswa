## Hari 3

### 🟢 Pemanasan

**Soal 1:** Fungsi `f(x) = x + 5`. Hitung f(0) dan f(3).

**Soal 2:** Fungsi `g(x) = 2x`. Hitung g(0), g(1), g(4).

**Soal 3:** Apa slope dari `f(x) = 4x + 1`?

### 🟡 Inti

**Soal 1:** Fungsi `f(x) = 3x − 1`. Buat tabel untuk x = 0, 1, 2, 3.

**Soal 2:** Dari tabel, tentukan fungsi:

| x | y |
|---|---|
| 0 | −2 |
| 1 | 1 |
| 2 | 4 |

### 🔴 Tantangan

**Soal:** f(0) = 1, f(2) = 5, f(4) = 9. Tentukan f(x), hitung f(10).

## Hari 4

### 🟢 Pemanasan

**Soal 1:** Fungsi `f(x) = 5x`. Hitung f(0), f(1), f(2).

**Soal 2:** Fungsi `h(x) = x − 3`. Hitung h(0), h(3), h(5).

**Soal 3:** Apa y-intercept dari `f(x) = 2x + 7`?

### 🟡 Inti

**Soal 1:** Fungsi `f(x) = −2x + 4`. Buat tabel untuk x = 0, 1, 2, 3.

**Soal 2:** Sebuah fungsi punya slope 3 dan y-intercept −1. Tulis fungsi dan hitung f(5).

### 🔴 Tantangan

**Soal:** Dua fungsi: f(x) = 2x + 1 dan g(x) = x + 3. Kapan f(x) = g(x)? (Cari x dimana kedua fungsi sama)

## Hari 5

### 🟢 Pemanasan

**Soal 1:** Fungsi `f(x) = x + 10`. Hitung f(−2) dan f(5).

**Soal 2:** Fungsi `g(x) = 3x + 1`. Hitung g(0) dan g(−1).

**Soal 3:** Apa slope dari `f(x) = −x + 5`?

### 🟡 Inti

**Soal 1:** Fungsi `f(x) = 4x − 3`. Buat tabel untuk x = −1, 0, 1, 2.

**Soal 2:** Dari grafik, titik-titik (0, 2), (2, 6), (4, 10). Tentukan fungsi.

### 🔴 Tantangan

**Soal:** Sebuah taksi: biaya buka Rp 7.000, lalu Rp 3.000 per km.
a) Tulis fungsi biaya sebagai f(x) = ... dimana x = km
b) Berapa biaya untuk 10 km?
c) Berapa km jika bayar Rp 40.000?

**Soal 1:** Fungsi `f(x) = 2x + 3`. Hitung f(0), f(1), f(5), f(−2).

**Soal 2:** Tentukan slope dan y-intercept dari `f(x) = −3x + 8`.

**Soal 3:** Dari tabel, tentukan fungsi:

| x | y |
|---|---|
| 0 | 5 |
| 2 | 9 |
| 4 | 13 |

**Soal 4:** Fungsi f(x) = 2x + 1 dan g(x) = 3x − 2. Hitung f(g(1)).

**Soal 5:** Jelaskan: kenapa fungsi linear selalu menghasilkan garis lurus saat digambar?
