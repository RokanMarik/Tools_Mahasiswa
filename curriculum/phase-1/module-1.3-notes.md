## 1. RINGKASAN KONSEP

Fungsi adalah aturan yang mengubah input menjadi output. Setiap input punya tepat satu output. Ditulis sebagai f(x) = aturan.

Fungsi linear (f(x) = mx + c) menghasilkan garis lurus saat digambar. m = slope (kemiringan), c = y-intercept (titik potong sumbu Y).

Slope = berapa naik y untuk setiap kenaikan x. Y-intercept = nilai y saat x = 0.

---

## 2. RUMUS PENTING

- **Fungsi linear:** `f(x) = mx + c`
- **Slope (m):** koefisien x
- **Y-intercept (c):** angka konstanta
- **Hitung nilai:** `f(a) = m(a) + c` (ganti x dengan a)
- **Cari x dari y:** `y = mx + c` → `x = (y − c) / m`

---

## 3. ANALOGI KUNCI

"Fungsi itu seperti mesin: masukkan bahan mentah (input), mesin bekerja (aturan), keluar produk jadi (output)."

"Slope itu seperti kemiringan jalan. Slope 2 = jalan naik tajam. Slope 0 = jalan datar. Slope negatif = jalan turun."

---

## 4. CONTOH KERJA

**Soal:** Fungsi `f(x) = 2x + 3`. Hitung f(4) dan tentukan slope + y-intercept.

**Jawaban:**
1. f(4) = 2(4) + 3 = 8 + 3 = 11
2. Slope = 2, y-intercept = 3

---

## 5. KESALAHAN UMUM

⚠️ f(2) untuk f(x) = 3x + 1 → 3 + 1 = 4 (salah, lupa kali) → Koreksi: 3(2)+1 = 7
⚠️ Slope f(x) = x + 5 → 5 (salah, slope = koefisien x = 1) → Koreksi: slope = 1
⚠️ Y-intercept f(x) = 2x → 0 ✅ (benar, tidak ada konstanta)
